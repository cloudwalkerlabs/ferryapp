Ferry

Share files and the clipboard with your phone. A KDE Connect client for macOS, Linux and Windows.

  • Download
  • Source
  • Sponsor

Ferry lets your computer and phone share files and the clipboard over the local network. There is no cloud service and no account; data goes directly between your devices. Ferry is open source and written in Rust, with one native app for macOS, Linux and Windows.

Ferry speaks the protocol of KDE Connect, the KDE project's app for connecting devices. Install KDE Connect on your phone, from Google Play or F-Droid (source), and Ferry on your computer, then pair them once.

Features

  • Send files, from a file picker or by dropping them on the window
  • Share the clipboard (text)
  • Browse a phone's files: download, upload, rename, delete and preview
  • See a device's battery level, ping it, or make it ring to find it
  • Tray icon, desktop notifications, and light and dark themes
  • Pairing confirmed with a code on both screens; TLS on every connection

macOS, with Homebrew

brew install simophin/tap/ferry

This installs Ferry into Applications and ferry-cli on your PATH, and brew upgrade keeps them up to date. Ferry isn't notarized by Apple, so if you download the DMG in a browser instead, macOS blocks it the first time: open System Settings → Privacy & Security and click Open Anyway. The Homebrew cask clears that mark for you.

Debian and Ubuntu

Add Ferry's apt repository, then install it and get updates with the rest of your system:

sudo curl -fsSLo /etc/apt/keyrings/ferry.gpg https://simophin.github.io/ferryapp/apt/ferry.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/ferry.sources https://simophin.github.io/ferryapp/apt/ferry.sources
sudo apt update
sudo apt install ferry

Debian 12, Ubuntu 22.04 and later, on x86_64 and arm64.

Arch Linux

Install ferry-app-bin from the AUR, e.g. yay -S ferry-app-bin.

Verifying downloads

Each release has a SHA256SUMS file listing its packages, signed with Ferry's release key, which also signs the apt repository. Its fingerprint is ECD3 B4C2 913B F64B 1664 F19F 074D A8D0 2070 102E: 

gpg --import ferry-release.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

The macOS app is signed with Ferry's own certificate, whose SHA-256 fingerprint is 71:30:53:6B:23:05:DB:1C:00:FB:00:C7:6C:8C:20:8A:34:BA:31:6B:F7:A8:F2:B6:3D:EF:32:24:4F:83:0B:5B (codesign -dvvv /Applications/Ferry.app shows it as "Ferry Code Signing").

Older versions and release notes are on GitHub Releases.

Status

Ferry is young. Pairing, clipboard sync and file transfer have been tested with KDE Connect for Android, but not yet with KDE Connect on other desktops. Known gaps are listed in ARCHITECTURE.md. Please report bugs on GitHub; pull requests are welcome.
